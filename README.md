# School Domino Pascal

An early Pascal programming project implementing a console domino game. The repository
preserves the original program as a historical school project.

Ранний учебный проект на Pascal с консольной игрой в домино. Репозиторий сохраняет
первоначальную программу как историческую школьную работу.

## Описание

Программа реализует консольную игру в домино и рисует костяшки простой ASCII графикой. Исходники сохранены в основном как исторический снимок раннего программного проекта, а не как современная реализация игры.

Внешних зависимостей, кроме компилятора Pascal, нет. Проект по-прежнему можно собрать с помощью Free Pascal в современной системе Linux.

## Разработка и проверка изменений

**Основные точки изменения:**

- `domino.pas` - единственный исходный файл: игровая логика, ввод и вывод в консоль.

**Путь игры:** `domino.pas` создаёт все 28 костей с числами от 0 до 6, функции `gen` и `gen1` случайно выбирают кости для сторон, а `kub` рисует одну половину кости тремя строками ASCII. `pere` разворачивает последовательность и меняет местами половины костей. Основной цикл обрабатывает текстовые команды `post`, `bank` и `pere` и меняет глобальные массивы `mas`, `mass*`. Это исходный учебный код: проверка индексов и вводимых строк не отделены в самостоятельный парсер. При правке команд проверяйте неправильные номера и пустой ввод, а при правке раздачи - отсутствие повторов в выбранных наборах.

**Проверка изменений:** Проект сохранён как исторический учебный код. Если меняете правила игры, проверяйте их ручным прохождением типовых и ошибочных ходов после сборки и запуска; модернизацию языка и рефакторинг лучше отделять от исправлений логики.

## Сборка и запуск

```sh
fpc domino.pas
./domino
```

Пример сборки и вывода:


## Реализация

Весь код находится в одном `domino.pas`. В нем реализованы генерация и раскладка костей, игровая логика и текстовое отображение домино непосредственно в терминале.

Проект оставлен в исходном виде как ранняя работа и пример того, с чего начиналось программирование до более поздних C/C++/networking проектов.
